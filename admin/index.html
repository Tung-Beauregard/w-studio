01 / PUBLISHING FLOW

從修改到上線，三個步驟。

  1. 01

    登入並選取網站

    開啟 Pages CMS，使用 GitHub 登入，選擇上方的儲存庫與 main 分支。

  2. 02

    修改文案或專案順序

    在「首頁文案」的「專案卡片順序」拖曳排序，按 X 隱藏卡片；要恢復時按「新增」選回原專案。文案仍可在各表單編輯。

  3. 03

    儲存並等待發布

    按下編輯器的 Save／儲存，變更會提交到 GitHub 並觸發 Pages 部署。通常需要幾分鐘，完成後重新整理網站。
